# Overview

This repository contains my implementation of the **National Student Data Corps (NSDC) Customer Segmentation Analysis Project**.

Understanding customer behavior is essential for businesses seeking to improve marketing strategies, personalize customer experiences, and make data-driven decisions. In this project, I applied **unsupervised machine learning** techniques to identify groups of customers with similar purchasing behaviors and demographic characteristics.

Working through the complete data science workflow, I explored data preprocessing, exploratory data analysis, feature engineering, clustering with **K-Means**, dimensionality reduction using **Principal Component Analysis (PCA)**, cluster visualization, and business interpretation. This project strengthened my understanding of customer analytics while demonstrating how machine learning can uncover hidden patterns in real-world data.

* Explore customer characteristics

## Data Preprocessing

Preparing customer data is an essential step before training clustering algorithms.

During preprocessing, I gained experience with:

* Cleaning datasets

* Scaling numerical features

* Preparing datasets for unsupervised learning

Proper preprocessing improved clustering quality and model performance.

## Exploratory Data Analysis (EDA)

Exploratory analysis helped identify relationships between customer attributes before clustering.

* Summary statistics
* Distribution analysis
* Correlation analysis

EDA provided valuable insights into customer behavior and purchasing patterns.

## Feature Engineering

Creating informative features is important for identifying meaningful customer segments.

During this project, I explored:

* Selecting useful customer variables
* Preparing features for clustering
* Improving dataset quality

Feature engineering helped produce more meaningful customer groupings.

## K-Means Clustering

The primary objective of this project was identifying customer segments using **K-Means clustering**.

During this stage, I learned how to:

* Apply unsupervised learning
* Group similar customers
* Compare cluster characteristics
* Interpret cluster assignments
* Build customer profiles

K-Means demonstrated how machine learning can automatically discover hidden customer groups without labeled outcomes.

## Cluster Evaluation

Selecting the correct number of clusters is an important part of customer segmentation.

During this project, I explored:

* Elbow Method
* Cluster inertia
* Comparing clustering solutions
* Selecting an appropriate number of customer groups

These techniques helped determine the most meaningful segmentation strategy.

PCA made it easier to understand relationships between customer groups.
